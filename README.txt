NIHAA BIRTHDAY WEBSITE — FINAL V1

Files:
- index.html
- photos/ (5 photos)
- audio/ (add your own recording as audio/perfect.mp3)

To publish:
1. Create/open your GitHub repository.
2. Upload index.html, the photos folder, and the audio folder.
3. Commit changes.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. Open the GitHub Pages URL shown there.

IMPORTANT:
The audio folder is intentionally empty. Add your own singing recording named:
perfect.mp3
Then upload it inside the audio folder.
